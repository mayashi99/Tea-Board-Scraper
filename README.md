##Tea Board Scraper 🇱🇰🍃

Overview

Tea Board Scraper is a Python-based web scraping project developed to collect tea-related statistical data from the official Sri Lanka Tea Board website and organize the collected information into Excel files for further analysis and research.

The project supports the collection and organization of Sri Lankan tea industry data, helping researchers and developers work with tea statistics more efficiently.

Official Data Source

Sri Lanka Tea Board: https://srilankateaboard.lk/

Tea Statistics: https://srilankateaboard.lk/tea-statistics/

The Sri Lanka Tea Board publishes tea industry information, including production, sales, and export statistics. The data collected by this project is sourced from its official website.

File Description

main.py — Main Python script for running the scraper.

modules/ — Directory containing the project's supporting modules.

page.html — HTML page file used by the project.

requirements.txt — List of Python dependencies required by the project.

export_all.xlsx — Excel file containing exported data.

tea_statistics.xlsx — Excel file containing tea statistics.

tea_statistics_all.xlsx — Excel file containing the collected tea statistics.

Technologies Used

Python — Core programming language.

Web Scraping — Collecting information from web pages.

HTML — Web page structure and content.

Microsoft Excel / XLSX — Storing and organizing collected data.
